# VitaPulse 全方位個人健康管家 (Personal Health Steward)

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache%202.0-0d9488.svg)](https://opensource.org/licenses/Apache-2.0)
[![React 19](https://img.shields.io/badge/React-19.0-2563eb.svg)](https://react.dev/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178c6.svg)](https://www.typescriptlang.org/)
[![Tailwind CSS v4](https://img.shields.io/badge/Tailwind_CSS-v4.3-06b6d4.svg)](https://tailwindcss.com/)

**VitaPulse 全方位個人健康管家** 是一款以「**居家實測精準度（100% 臨床可量測指標）**」與「**本地隱私優先（Local-First Privacy）**」為核心打造的開源個人健康管理系統。

本專案全面**移除無用、困難且不準確的估算功能**（如未經雙能 X 光儀器校準的體脂率公式猜測、未經睡眠腦波儀量測的深層睡眠/REM 階段猜測、或隨機無意義數據模擬按鈕），僅保留一般人在家透過**體重計、軟皮尺、血壓計與碼錶**即可 100% 精準量測並獲醫學實證支持的健康指標。同時針對開源展示需求，內建「**GitHub 公開演示模式防止關閉**」與「**自己部署 (Self-Hosted) 自由關閉**」雙重部署權限策略。

## ✨ 核心功能亮點

### 1. 身體組成、腰身高比 (WHtR) 與居家血壓分析
- **雙重 BMI 判定標準即時切換**：完整支援 **台灣衛生福利部國民健康署 (HPA)** 標準（正常體位 `18.5 ≤ BMI < 24.0`、過重 `24.0–26.9`、輕度/中度/重度肥胖）與 **WHO 世界衛生組織國際標準**。
- **理想體重區間 (BMI 22 黃金基準)**：自動計算個人身高對應之正常體重上下限，並提供「距離理想體重或正常邊界之精確公斤數差距」。
- **基礎代謝率 (BMR) 與總熱量消耗 (TDEE)**：採用臨床營養學最準確之 **Mifflin-St Jeor 公式**，結合 5 級日常活動量係數（久坐至高強度運動）計算每日熱量基準。
- **腰身高比 (WHtR) 與腰臀比 (WHR) 內臟脂肪評估**：摒棄容易失準的體脂公式估算，改採醫學界公認更準確的皮尺量測指標「腰圍 ÷ 身高 (WHtR < 0.50)」與「腰圍 ÷ 臀圍 (WHR)」評估中心型肥胖與內臟脂肪風險。
- **台灣高血壓學會 722 居家血壓分級**：依據最新臨床指引（`< 120/80 mmHg` 正常、`120–129/<80` 偏高、`≥ 130/80` 高血壓第 1/2 期）即時判定心血管負荷。

### 2. GitHub 公開演示防止關閉 vs 自己部署自由關閉機制
- **GitHub 公開演示部署 (`github-pages` 模式)**：
  - 當部署至 GitHub Pages (`*.github.io`) 或設定環境變數 `VITE_GITHUB_DEMO="true"` 時，系統會**自動鎖定「演示模式 (Demo Mode)」與「防止誤關視窗保護 (BeforeUnload)」為強制開啟狀態（防止關閉）**，並禁止公開訪客清空預設展示歷史紀錄，確保開源專案線上 Demo 永遠維持最佳展示狀態。
- **自己部署自架模式 (`self-hosted` 模式)**：
  - 當您自行克隆專案部署於個人電腦、私有伺服器、Vercel/Docker，或於介面切換至「**自己部署模式 (Self-Hosted)**」時，系統會**完整解鎖控制權**：您可以**隨時自由關閉「演示模式」**（切換為純個人自用健康檔案、一鍵清空預設範例紀錄），並可**自由關閉或開啟「防止誤關視窗保護」**。

### 3. 互動式歷史健康趨勢圖表 (Multi-Metric SVG Trend Engine)
- 支援 **BMI 身體質量指數**、**體重 (kg)**、**腰圍 (cm)**、**睡眠品質評分**、**每日飲水量 (ml)**、**靜息心率 (bpm)** 與 **壓力負荷指數** 共 7 大維度的歷史趨勢折線與面積圖表切換。
- 內建臨床正常目標參考區間帶（Reference Band）、首末期淨變化量（Delta）與平均值統計，並提供關鍵字搜尋與體位狀態篩選。

### 4. 八維度健康問卷評分與分級改善處方
- 涵蓋 **飲食原型食物比例、精緻糖與加工食品控制、有氧與肌力訓練頻率、久坐中斷與日行步數、睡眠時數與規律性、日常水分攝取習慣、心理壓力調適、菸酒與夜間咖啡因控制** 共 8 大維度（總分 `0–100` 分，分為 `S / A / B / C / D` 五級）。
- 自動針對弱項生成具優先級標籤（`亟需改善`、`建議強化`、`維持良好`）的具體改善行動方案與預期健康效益。

### 5. 每日三大營養素目標與運動處方追蹤
- 依據個人目標（**減脂減重 `-18% kcal`、增肌減脂體態重組 `-8% kcal`、健康維持 `100% TDEE`、增肌強化 `+12% kcal`**）自動計算每日蛋白質、碳水化合物、健康脂肪克數與膳食纖維建議量。
- 內建每週有氧運動分鐘數、肌力訓練次數與今日步數互動式打卡進度條。

### 6. 實用睡眠效率監測與定時水分攝取提醒管家
- **可觀察睡眠效率法**：無需手環猜測深淺眠比例，只需記錄真實「就寢時間、起床時間、入睡耗時（睡眠潛伏期）、半夜醒來次數」與「晨起精神恢復感 (1–5 分)」，即可精準算出臨床**睡眠效率（實際睡眠時數 ÷ 躺床總時數，標準 ≥ 85%）**與綜合評分。
- **智慧水分攝取管家**：依「體重 `× 35 ml` + 活動量補償」計算每日個人化飲水目標，提供 `+150ml / +250ml / +350ml / +500ml` 快速飲水打卡與自訂間隔（45 / 60 / 90 / 120 分鐘）即時倒數提醒計時器。

### 7. 15 秒標準脈搏換算、心率區間與壓力負荷分析
- **15 秒標準脈搏量測法**：內建 15 秒碼錶計時器，將食指與中指輕按手腕內側橈動脈默數 15 秒跳動次數，系統自動乘以 4 換算為標準每分鐘靜息心率 (BPM)。
- **Karvonen 儲備心率五級訓練區間**：結合田中公式 (`208 - 0.7 × 年齡`) 與儲備心率 (`HRR = MaxHR - RestingHR`)，精確計算 Zone 1 動態恢復至 Zone 5 無氧極限區間（特別標示 **Zone 2 最佳燃脂與粒線體有氧區間**）。
- **4-7-8 副交感神經減壓呼吸訓練器**：內建吸氣 4 秒、屏息 7 秒、吐氣 8 秒互動式讀秒計時器，協助即時降低交感神經張力。

### 8. 嚴格 PIN 碼鎖定（已移除快速略過後門）與跨裝置備份
- **100% 本地端儲存 (`localStorage`)**：所有健康資料僅保存在使用者瀏覽器本地端，絕不自動上傳至任何第三方伺服器。
- **公共場合防窺遮罩**：一鍵將身高、體重、BMI、腰圍與血壓等敏感數字遮蔽為 `••.•`。
- **嚴格本地 PIN 碼安全鎖**：已完全移除「快速略過 (示範)」按鈕，且鎖定狀態同步寫入 `sessionStorage`，重新整理網頁亦無法繞過，必須輸入正確的 4–6 位數 PIN 安全碼方可解鎖；停用自動鎖定時亦須驗證原 PIN 碼。
- **完整資料可攜性**：支援匯出完整 **JSON 備份檔**（可跨電腦/手機一鍵無損還原）與 **CSV 試算表報表**（含 UTF-8 BOM，可直接以 Excel / Numbers 開啟）。

## 🚀 安裝指令與本地啟動指南 (Installation & Setup)

### 環境需求 (Prerequisites)
- **Node.js**: 建議 `v18.18.0` 或 `v20.0.0` 以上版本
- **套件管理器**: `npm` (v9+)、`pnpm` 或 `yarn`

### 1. 複製專案儲存庫 (Clone Repository)
```bash
git clone https://github.com/your-username/vitapulse-health-steward.git
cd vitapulse-health-steward
```

### 2. 安裝專案依賴套件 (Install Dependencies)
```bash
npm install
```

### 3. 設定環境變數 (GitHub 演示部署 vs 自己部署)
複製 `.env.example` 為 `.env`：
```bash
cp .env.example .env
```
- **自己部署 (Self-Hosted 預設)**：保持 `VITE_GITHUB_DEMO="false"`（或不設定），即可於網頁中自由關閉「演示模式」與「防止誤關視窗保護」。
- **部署至 GitHub Pages 公開展示**：若網域為 `*.github.io` 或於建置時設定 `VITE_GITHUB_DEMO="true"`，系統將自動啟動「演示模式防止關閉」與「防誤關視窗鎖定」。

### 4. 啟動本地開發伺服器 (Start Development Server)
```bash
npm run dev
```
啟動後請於瀏覽器開啟 `http://localhost:3000` 即可使用完整功能。

### 5. 執行核心健康演算法單元測試 (Run Unit Tests)
```bash
npx tsx --test src/utils/healthCalculations.test.ts
```

### 6. 建置正式環境靜態檔案 (Build for Production)
```bash
npm run build
npm run preview
```

## 📖 使用說明指南 (User Guide)

### 第一步：切換部署模式與防止關閉設定（頂部工具列 / 使用說明頁）
1. **GitHub 公開演示模式 (`GitHub 演示部署`)**：
   - 適用於將專案部署在 GitHub Pages 供他人試用時。此模式下「**演示模式**」與「**防止誤關視窗保護**」均為**強制鎖定開啟狀態（防止被訪客關閉）**，且鎖定「清空歷史」按鈕。
2. **自己部署模式 (`自己部署模式`)**：
   - 當您自己部署使用時，點擊工具列或「使用說明」頁右上角的「**自己部署模式 (可自由關閉)**」，即可自由點擊關閉「演示模式」（並可一鍵清空預設範例紀錄，從零開始建立個人健康檔案），亦可自由關閉或開啟「防止誤關視窗保護」。
3. **嚴格 PIN 碼鎖定（無快速略過按鈕）**：
   - 點擊「**PIN 鎖定**」可立即鎖定健康儀表板（預設安全碼為 `2580`，可於「歷史趨勢與隱私」頁面修改為自訂 4~6 位數密碼）。鎖定畫面已完全移除示範略過按鈕，確保個人隱私安全。

### 第二步：身體組成與腰身高比 (WHtR) 評估（身體組成與總覽頁）
1. 於左側表單輸入**身高 (cm)**、**晨起空腹體重 (kg)**、**年齡**、**腰圍 (cm)**、**臀圍 (cm)** 與**晨晚血壓 (mmHg)**。
2. 右側面板將即時更新 **BMI 指數**、**理想體重範圍**、**BMR / TDEE 熱量**、**腰身高比 (WHtR)**、**腰臀比 (WHR)** 與 **722 血壓分級**。
3. 輸入今日生活備註後點擊「**儲存今日快照**」，即可將今日數據寫入歷史趨勢圖表。

### 第三步：完成八維度健康問卷與營養運動打卡（健康問卷與處方頁）
1. 依實際生活型態點選 8 道日常習慣問題，右側立即計算 `0–100` 健康生活評分並列出 `亟需改善` / `建議強化` 處方。
2. 於下方選擇您的健康目標（減脂、體態重組、維持或增肌），系統將自動換算每日蛋白質、碳水與脂肪目標克數，並可記錄每週有氧運動分鐘數、肌力訓練次數與今日步數。

### 第四步：睡眠效率紀錄與飲水定時提醒（睡眠與飲水管家頁）
1. **飲水打卡**：點擊 `+150ml`、`+250ml`、`+350ml` 或 `+500ml` 快速累加今日飲水量，並可開啟定時飲水提醒倒數。
2. **睡眠效率計算**：輸入昨晚就寢時間、今晨起床時間、入睡耗時、半夜醒來次數與晨起精神恢復感 (1–5 分)，系統即自動計算實際睡眠時數與臨床睡眠效率。

### 第五步：15 秒脈搏計時與 4-7-8 減壓呼吸（心率與壓力分析頁）
1. 點擊「**15秒計時**」並測量手腕橈動脈 15 秒跳動次數，系統自動乘以 4 換算為每分鐘靜息心率 (BPM)，並同步計算 **Karvonen 五級運動心率區間**。
2. 當壓力負荷偏高時，點擊「**啟動 4-7-8 減壓呼吸引導**」，跟隨畫面讀秒進行呼吸放鬆。

### 第六步：跨裝置 JSON / CSV 資料備份與還原（歷史趨勢與隱私頁）
1. 點擊「**匯出 JSON 備份**」可將所有個人資料、歷史紀錄、睡眠與飲水日誌打包下載至本地電腦或手機。
2. 更換裝置時，只需點擊「**匯入還原 JSON 備份檔**」選擇該檔案，即可 100% 完整還原所有健康數據。

## ⚕️ 醫療免責聲明 (Medical Disclaimer)

本軟體（VitaPulse 全方位個人健康管家）提供之身體質量指數 (BMI)、基礎代謝率 (BMR)、腰身高比 (WHtR)、健康問卷評分、營養攝取建議、睡眠效率、運動心率區間與壓力負荷指數，皆基於公開發表之流行病學與運動生理學公式（台灣衛福部國民健康署、WHO、Mifflin-St Jeor、Karvonen 公式）推算，**僅供個人日常健康管理與生活型態改善參考，不具任何醫療診斷或處方效力**。若您有慢性疾病、心血管症狀、睡眠障礙或特殊飲食需求，請務必諮詢合格醫師、臨床營養師或專業醫療人員。
